# Еталони для генерації (текст роботи + презентація + практика)

Еталонні матеріали для скілів `/generate-diplom`, `/generate-presentation` та
`/generate-shodennyk`: захищена кваліфікаційна робота бакалавра
Національного університету «Одеська політехніка» (**текстова частина**, що
**відповідає** правилам з `../RULES.md`), дві захищені **презентації** до захисту
та зразки **щоденника переддипломної практики** (+ архівний зразок звіту). Слугують
зразком структури, обсягу, стилю й оформлення.

## Файли

| Файл | Що це |
|---|---|
| `sample-work.pdf` | Повний текст роботи, 90 с. (вирізаний з PKCS#7-конверта). Канонічний візуальний еталон тексту. |
| `sample-work.txt` | Витягнутий текст (cid-розкодований) для grep/аналізу структури. |
| [`PRESENTATION-RULES.md`](./PRESENTATION-RULES.md) | Правила оформлення презентації до захисту (структура слайдів + чек-ліст), нормалізовані з обох еталонних `.pptx`. |
| `sample-presentation-1.pptx` | Компактний еталон презентації — 8 слайдів, 16:9. |
| `sample-presentation-2.pptx` | Повний еталон презентації — 12 нумерованих слайдів, 16:9 (таблиця аналогів, діаграми, стек, контрольний приклад). |
| [`SHODENNYK-RULES.md`](./SHODENNYK-RULES.md) | Правила оформлення щоденника практики (повна офіційна форма + чек-лист консистентності). Використовується `/generate-shodennyk` / `/grill-shodennyk`. |
| `Щоденник.docx` | Зразок щоденника переддипломної практики. Еталон фіксованої форми: титульний блок, прибуття/вибуття, індивідуальне завдання, Календарний графік, Робочі записи, відгуки керівників, оцінка. |
| [`practice/`](./practice/README.md) | Матеріали переддипломної практики (гр. АС-22): методичні вказівки 121, офіційний зразок щоденника, наказ, 175 реальних заповнених щоденників. Джерела для `/generate-shodennyk`. |
| [`ZVIT-RULES.md`](./ZVIT-RULES.md) | *Архівне, reference-only* — правила оформлення звіту з практики. Більше не підключене до жодного скіла (генерацію звіту прибрано). |
| `Звіт.docx` | *Архівне, reference-only* — зразок звіту з переддипломної практики (NeoFauna, гр. АС-223). Зберігається як довідка; не використовується скілами. |

## Метадані еталона

- **Тема:** Вебзастосунок для побудови моделі розробника програмного забезпечення
- **Автор:** Аліна Скрипнікова (група ЗАС-211)
- **Керівник:** Олексій Кунгурцев
- **Спеціальність:** 121 Інженерія програмного забезпечення
- **ОПП:** Інженерія програмного забезпечення
- **Рівень:** бакалавр, 2026
- **Інститут / кафедра:** Інститут дистанційної і заочної освіти / Кафедра інженерії програмного забезпечення
- **Обсяг:** 90 с. (основна частина 74 с., 12 джерел на 2 с., додатки 9 с.)

## Структура еталона (зразок розбиття на розділи)

- Вступ
- 1 Специфікація вимог до вебзастосунку (предметна область, аналіз аналогів, функц./нефункц. вимоги, вимоги до UI, варіанти використання)
- 2 Планування проекту з розробки вебзастосунку (масштаби, ризики)
- 3 Алгоритм підбору розробників (положення, формування вимог, фільтрація, оцінювання, рейтинг)
- 4 Проєктування вебзастосунку (моделі, архітектура, БД)
- 5 Програмна реалізація вебзастосунку (інструменти, реалізація сервісу)
- 6 Тестування вебзастосунку (функц./нефункц.)
- 7 Експлуатація застосунку (робота користувача, приклад підбору)
- Кожен розділ завершується «Висновки до розділу N»
- Загальні висновки → Список використаних джерел → Додатки

## Еталони практики (`Щоденник.docx`, `practice/`)

`Щоденник.docx` (проєкт NeoFauna, гр. АС-223) і матеріали в [`practice/`](./practice/README.md)
(методичні вказівки 121, офіційний зразок `shodennyk-zrazok.pdf`, 175 реальних заповнених
щоденників гр. АС-22) — самостійні приклади **щоденника** переддипломної практики, не
повʼязані з текстом `sample-work.pdf`. Використовуються `/generate-shodennyk` і
`/grill-shodennyk` суто як зразки форми й оформлення; зміст для конкретної роботи береться
з `thesis/`.

> `Звіт.docx` і `ZVIT-RULES.md` лишаються в репозиторії як **архівні reference-only**
> матеріали — генерацію звіту з практики прибрано, скіли їх більше не використовують.
