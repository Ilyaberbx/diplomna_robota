# Еталони та приклади переддипломної практики (гр. АС-22)

Матеріали Національного університету «Одеська політехніка» для генерації та перевірки
**щоденника переддипломної практики** (`/generate-shodennyk`, `/grill-shodennyk`).
Слугують першоджерелом офіційної форми та зразками того, як її **насправді заповнюють**.

## Файли

| Файл | Що це |
|---|---|
| `metodychni-vkazivky-praktyka-121-2025.pdf` / `.docx` | **Офіційні методичні вказівки** до виробничої та переддипломної практик за спеціальністю 121 (укл. Любченко, Зіноватна, Оніщенко; затв. кафедрою ІПЗ, протокол №1 від 2025-08-29). §5 «Структура та правила оформлення звіту та щоденника практики» — першоджерело, з якого виведено `../SHODENNYK-RULES.md`. Тут також: мета й завдання практики, індивідуальне завдання, критерії оцінювання. |
| `shodennyk-zrazok.pdf` | Офіційний **зразок щоденника** (бланк-форма). Візуальний еталон розкладки — доповнює `../Щоденник.docx`. |
| `nakaz-praktyka-4-kurs-2026.docx` | Наказ про практику 4 курсу (2026): реальні дати, групи, закріплені керівники. Контекст для метаданих/періоду. |
| `examples/` | **175 реальних заповнених щоденників** студентів гр. АС-22. Зразки фактичних патернів заповнення: підприємство = ФОП, період на 4 тижні, Календарний графік ↔ Робочі записи, оформлення звіту як завершальна робота практики. |

## Як це використовують скіли

- **`/generate-shodennyk`** бере звідси форму (`shodennyk-zrazok.pdf`, методичні вказівки §5)
  і приклади заповнення (`examples/`), а зміст/метадані — з `thesis/`. Самі приклади — це
  зразок **форми**, не джерело змісту конкретної роботи.
- **`/grill-shodennyk`** звіряє згенерований `shodennyk.docx` із цією формою та правилами
  `../SHODENNYK-RULES.md`.

## Чого тут навмисно немає

- **Відеозаписи зустрічей** (~178 МБ, 2× `.mp4`) — не копіюємо в репозиторій (вага).
- **Правила оформлення текстової частини** (`pravyla_oformlennya…pdf`) — **дублікат** уже
  наявного `docs/diploma-rules/pravyla-full.pdf` (однаковий md5), тому не копіюється.

## Примітка про персональні дані

`examples/` містить реальні ПІБ студентів гр. АС-22 (особисті дані). Використовувати лише
як приклад форми заповнення; не публікувати окремо й не виносити за межі репозиторію.
