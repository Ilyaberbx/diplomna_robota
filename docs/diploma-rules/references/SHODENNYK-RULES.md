# Правила оформлення щоденника переддипломної практики

**Заклад:** Національний університет «Одеська політехніка».
**Природа документа:** офіційна друкована **бланк-форма** щоденника практики.
**Зразок:** `Щоденник.docx` (проєкт NeoFauna, гр. АС-223).

> Щоденник — **фіксована форма**, а не вільний текст. Друк готовий до підпису: усі
> поля підписів, печаток і оцінок лишаються **порожніми бланками** (заповнюються від
> руки / печаткою). Решта (метадані, графік, робочі записи, індивідуальне завдання)
> — заповнена. Текстові константи (A4, поля, Times New Roman 14 пт) — за `../RULES.md`
> §1. За розбіжності перевагу має офіційний бланк (`Щоденник.docx`).

---

## 0. Природа документа

- Документ повторює **офіційну форму**: блоки, печатки, рядки підписів — на місці,
  навіть якщо лишаються незаповненими.
- Заповнюється з боку здобувача: метадані, індивідуальне завдання, Календарний графік,
  Робочі записи. З боку керівників/підприємства — лишаються **порожні бланки**.
- Не вигадувати підписів, печаток, оцінок, відгуків посадових осіб.

## 1. Обовʼязкові блоки у порядку

1. **Титульний блок** — «ЩОДЕННИК ПРАКТИКИ», вид практики (переддипломна), ПІБ
   здобувача, інститут, кафедра, освітньо-кваліфікаційний рівень (Бакалавр),
   спеціальність (121), освітня програма, курс і група, підприємство, період.
2. **Прибуття / вибуття** — рядки «Прибув на підприємство … (дата)» / «Вибув з
   підприємства … (дата)» + клітинки печаток (**М.П.**, порожні) + рядок підпису
   відповідальної особи.
3. **Індивідуальне завдання** на практику (текст).
4. **Календарний графік проходження практики** (таблиця — §2).
5. **Робочі записи під час практики** (датовані діапазонами записи — §3).
6. **Відгук і оцінка роботи здобувача на практиці від підприємства** (текст відгуку
   + підпис керівника від підприємства + **М.П.** — бланки порожні).
7. **Відгук керівника практики від університету** + **висновок** про проходження
   (бланк порожній).
8. **Оцінка** — за національною шкалою (відмінно/добре/задовільно) + за шкалою **ECTS**
   (A–F); клітинки порожні; дата складання заліку, підпис керівника від університету
   — бланки.

## 2. Схема таблиці «Календарний графік»

- Стовпці: **№ з/п | Назви робіт | Тиждень 1 | Тиждень 2 | Тиждень 3 | Тиждень 4 |
  Відмітки про виконання**.
- Рядки = укрупнені роботи практики; у відповідних тижнях ставиться позначка
  виконання (`х` / `+`).
- **Назви робіт відповідають структурі звіту** (розділи 1–2 та його ВСТУПу): типово
  аналіз предметної області → аналіз аналогів → вимоги → проєктування архітектури →
  проєктування БД / специфікації класів → оформлення звіту.
- «Відмітки про виконання» — **порожній бланк** (підписує керівник).

## 3. Формат «Робочі записи під час практики»

- Кожен запис: **діапазон дат** «РРРР-ММ-ДД – РРРР-ММ-ДД» (ISO 8601), далі опис
  виконаних за період робіт.
- Діапазони **покривають увесь період практики без розривів і перекриттів**.
- Кожен діапазон відповідає принаймні одному рядку Календарного графіку (роботи з
  графіку зʼявляються в робочих записах у відповідні тижні).

## 4. Правила консистентності (крос-документні)

- **ПІБ здобувача, група, спеціальність, ОПП** == титул звіту == `thesis/00-tytulnyi-arkush.md`.
- **Назва підприємства** == ХАРАКТЕРИСТИКА ПІДПРИЄМСТВА звіту (`ZVIT-RULES.md` §4) ==
  титул щоденника.
- **Період практики** (початок / кінець) == титул звіту; робочі записи в межах періоду.
- **Керівник від університету** == керівник у `thesis/00-tytulnyi-arkush.md`.
- **Теми робіт** у Календарному графіку узгоджені з розділами звіту.

## 5. Машинно-перевірюваний чек-лист (повнота форми)

- [ ] Усі 8 блоків (§1) присутні в правильному порядку.
- [ ] Титульний блок містить ПІБ / групу / спеціальність / ОПП / підприємство / період.
- [ ] Прибуття/вибуття + клітинки **М.П.** присутні (порожні).
- [ ] Індивідуальне завдання присутнє.
- [ ] Календарний графік: 7 стовпців за §2; тижні 1–4; ≥1 рядок робіт.
- [ ] Робочі записи: ≥1 датований діапазон; покривають період без розривів.
- [ ] Відгук підприємства + підпис/М.П. (бланки) присутні.
- [ ] Відгук керівника від університету + висновок (бланк) присутні.
- [ ] Блок оцінки: національна шкала + ECTS (бланки) присутні.

## 6. Чек-лист крос-консистентності зі звітом

- [ ] enterprise == `zvit-03-harakterystyka`.

- [ ] роботи Календарного графіку ↔ розділи звіту.
