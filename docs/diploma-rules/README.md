# Правила оформлення дипломної (кваліфікаційної) роботи

Локальна копія офіційних правил Національного університету «Одеська політехніка»
для оформлення текстової частини кваліфікаційних робіт бакалавра та магістра.
Дипломна робота в цьому репозиторії пишеться **на основі цих правил**.

## Вміст

| Файл | Що це |
|---|---|
| [`RULES.md`](./RULES.md) | **Головний документ** — нормалізований конспект усіх правил з числовими константами та чек-лістом. Читати першим. |
| `pravyla-proj.pdf` | Читабельна копія повного офіційного PDF (66 с., вкл. Додатки А–Д). |
| `pravyla-full.pdf` | Підписаний оригінал (PKCS#7-конверт). Юридично автентитчний, але не читається напряму. |
| `pravyla-raw.txt` | Сирий текст, витягнутий з PDF (для grep/перевірок). |
| `appendices/dodatok-a-tytulnyi-arkush.docx` | Зразок оформлення титульного аркуша. |
| `appendices/dodatok-b-anotacii.docx` | Зразок оформлення анотацій (укр + ABSTRACT). |
| `appendices/dodatok-v-zmist.docx` | Зразок оформлення змісту. |
| `appendices/dodatok-g-vstup.docx` | Зразок оформлення вступу. |

> Додаток Д (приклади бібліографічних описів за ДСТУ 8302:2015) міститься
> всередині `pravyla-proj.pdf` — окремого DOCX для нього офіційно не публікується.
