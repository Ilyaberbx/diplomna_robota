## Інститут — критична фіксація

Назва навчально-наукового інституту — **«Навчально-науковий інститут комп'ютерних
систем»** і **тільки так**.

- **НЕ** «Інститут комп'ютерних систем» (без «Навчально-науковий»).
- **НЕ** будь-яке інше скорочення чи перефразування.

Підстава: пряме зауваження малої комісії (1-й пункт ревю 2026-06-06) — у титулі бракувало
слів «Навчально-науковий». Виправлено; це значення зафіксовано тут, щоб жодне наступне
перескладання його не відкотило.
